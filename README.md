# ISEScriptingGeek

A professional PowerShell 5.1 toolkit by Jeff Hicks providing ISE editor integration and scripting automation.

**31 PowerShell scripts** (~2,100 lines) organized into functional clusters:
- Text manipulation & code conversion
- Script analysis & introspection
- File/tab management
- Function & help generation
- Bookmarking and navigation
- Specialized utilities (Word export, CIM templates, DSC snippets)
